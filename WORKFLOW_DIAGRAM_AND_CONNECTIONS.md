## Key Takeaway

**The fix is simple:**
- Change non-nullable types to nullable types (add `?`)
- When the database has nullable fields, C# model must allow nulls
- `int?`, `DateTime?`, `string?` can be null
- `int`, `DateTime` CANNOT be null (will crash if given null)
