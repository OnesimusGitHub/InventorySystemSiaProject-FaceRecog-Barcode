## What Gets Updated

```
MongoDB UpdateMany Operation:

FIND: All documents where:
  - quantity field doesn't exist, OR
  - quantity field is null

UPDATE: Set quantity = 0 for all matching documents

RESULT: Every EmployeeActivity record now has a quantity field
```
